# Real-Time Embedded System Project

## Selected System: Smart Traffic Light Controller

This project models a real-time embedded system responsible for controlling the traffic lights at a four-way intersection. The system operates based on strict timing constraints and ensures safe transitions between light states.

### System Goals
- Manage light states (Red, Yellow, Green)
- Prevent conflicting traffic flows
- Maintain precise timing for each state
- Provide a foundation for adding sensors in future sessions
